# WiFi RSSI 3D Indoor High-Fidelity Simulation (MATLAB)

This repository provides a high-fidelity MATLAB simulation for WiFi RSSI propagation in a complex 3D indoor environment, designed for localization and sensing experiments.

The core implementation is in `wifi_rssi_simulation.m` and includes:
- Configurable 3D room geometry
- Material-aware obstacles (walls/furniture)
- Multiple APs with channel overlap interference
- LOS + multipath reflections (image-source style ray tracing)
- Log-normal shadowing and Rayleigh/Rician small-scale fading
- Dynamic human attenuation with trajectories
- Structured outputs for ML/localization pipelines
- 3D/2D visualization and optional animation

## 1. Repository Structure

- `wifi_rssi_simulation.m`: Main simulation script with all modular local functions
- `output/wifi_rssi_results.mat`: Binary MATLAB results (generated after running)
- `output/wifi_rssi_results.csv`: Flattened table for external processing (generated after running)

## 2. Quick Start

## 2.1 Requirements

- MATLAB R2020b+ (recommended)
- No required external toolbox for the current script logic

## 2.2 Run

From MATLAB:

```matlab
run('wifi_rssi_simulation.m')
```

After completion, it will generate:
- A `.mat` file with full structures
- A `.csv` file with per-point/per-AP/per-time measurements
- Figures for 3D environment, heatmap slice, and 3D RSSI scatter
- Optional dynamic animation (if enabled)

## 3. Example Scenario Included

The script ships with a default demo scenario:
- Room: `10 m x 10 m x 3 m`
- APs: 3 APs in 3D positions near ceiling
- Obstacles: 2 obstacles (partition wall + cabinet)
- Human: 1 moving human modeled as a vertical cylinder with waypoints
- Grid: 3D measurement grid sampled at configurable spacing
- Time: dynamic simulation over configurable duration and step

## 4. Model Architecture

The simulation is modular and implemented through local functions:

- `defaultSimulationConfig`: global simulation parameters
- `createExampleScenario`: room/AP/obstacle/human creation
- `createMeasurementGrid`: 3D receiver grid generation
- `runRssiSimulation`: main dynamic simulation loop
- `computeReceivedPowerDbm`: per-link propagation model
- `buildImageSources` + `reflectedComponents`: multipath/reflection model
- `computeObstacleLossDb`: penetration attenuation through obstacles
- `computeHumanLossDb`: dynamic human body attenuation
- `channelOverlapFactor`: co-channel interference weighting
- `smallScaleFadingGain`: Rayleigh or Rician fading
- Visualization functions: environment plot, 2D slice, 3D scatter, animation
- `exportSimulationData`: `.mat` + `.csv` export

## 5. Detailed Algorithms

## 5.1 Geometric and Material Model

Room and objects are represented in a Cartesian 3D frame.
- Room boundaries: six axis-aligned planes (`x=0, x=L, y=0, y=W, z=0, z=H`)
- Obstacles: axis-aligned boxes with material fields:
  - `reflectionCoeff` (amplitude reflection coefficient)
  - `absorptionCoeff`
  - `attenuationDbPerMeter`
- Humans: finite vertical cylinders with radius, height, and attenuation per meter

## 5.2 Path Loss (LOS baseline)

For AP-receiver distance `d`:

1. Wavelength

\[
\lambda = \frac{c}{f}
\]

2. FSPL at reference distance `d0 = 1 m`

\[
\text{FSPL}_{1m}(dB) = 20\log_{10}\left(\frac{4\pi d_0}{\lambda}\right)
\]

3. Log-distance path loss

\[
PL(dB) = \text{FSPL}_{1m} + 10n\log_{10}\left(\frac{d}{d_0}\right)
\]

where `n` is the configurable path loss exponent.

Received LOS power before multipath combination:

\[
P_{r,LOS}(dBm) = P_t(dBm) - PL - L_{obs} - L_{human} - L_{NLOS} + X_\sigma
\]

- `L_obs`: obstacle penetration loss
- `L_human`: human attenuation
- `L_NLOS`: penalty when LOS is blocked
- `X_sigma ~ N(0, sigma^2)` in dB for log-normal shadowing

## 5.3 Obstacle Penetration Loss

For each obstacle box, the script computes the segment length inside the box using a slab intersection algorithm.

If inside length is `\ell`:

\[
L_{obs,i}(dB) = \ell \cdot \alpha_i + 1.5\ell\cdot a_i
\]

- `alpha_i = attenuationDbPerMeter`
- `a_i = absorptionCoeff`

Total obstacle loss is the sum over all crossed obstacles.

## 5.4 Human Attenuation

A human body is approximated as a finite vertical cylinder. The script computes AP-receiver segment intersection length inside the cylinder:

\[
L_{human,j}(dB) = \ell_j \cdot \beta_j
\]

- `\beta_j = attenuationDbPerMeter` for human `j`

Total human loss sums over all humans present.

## 5.5 NLOS / Diffraction Penalty

If LOS is blocked by obstacle/human intersection, an additional penalty is applied:

\[
L_{NLOS} = L_{nlosPenalty} + L_{diffractionPenalty}
\]

This is a simplified but practical approximation for blockage and diffraction effects.

## 5.6 Multipath Reflection Model (Image Source)

When enabled, reflections are generated by mirroring AP locations across room boundary planes up to configurable order `R`.

For each reflected path `k`:
- geometric distance: `d_k`
- reflection amplitude gain from material coefficients:

\[
g_k = \prod_{r\in path_k} \left(\rho_r(1-a_r)\right)
\]

with `rho = reflectionCoeff`, `a = absorptionCoeff`.

Reflected path power (in dBm before field summation):

\[
P_{r,k}(dBm) = P_t - PL(d_k) - L_{refl,k} - L_{obs,k} - L_{order,k}
\]

where `L_refl,k = -20 log10(g_k)`.

The total received signal uses complex field superposition:

\[
E_{tot}(f) = \sum_k \sqrt{P_{r,k}^{lin}}e^{-j2\pi f d_k/c} + \sqrt{P_{r,LOS}^{lin}}e^{-j2\pi f d_{LOS}/c}
\]
\[
P_{tot}^{lin}(f)=|E_{tot}(f)|^2
\]

## 5.7 Frequency-Selective Fading (Optional)

If enabled, the script evaluates multiple subcarrier offsets over configured bandwidth and averages power:

\[
P_{avg}^{lin} = \frac{1}{N_{sc}}\sum_{m=1}^{N_{sc}} P_{tot}^{lin}(f_m)
\]

This approximates frequency-selective behavior in OFDM-like systems.

## 5.8 Small-Scale Fading

After multipath aggregation, an additional random fading gain is applied:

- Rayleigh:
  - `h ~ CN(0,1)`
  - gain `G = |h|^2`

- Rician:
  - `K = 10^(K_dB/10)`
  - `h = sqrt(K/(K+1)) + sqrt(1/(2(K+1))) * (nI + j nQ)`
  - gain `G = |h|^2`

Final link power:

\[
P_r^{lin} = P_{avg}^{lin} \cdot G
\]

## 5.9 AP Interference and Noise

For target AP `a`, interference from AP `b` is weighted by spectral overlap:

\[
\eta_{ab} = \max\left(0, 1 - \frac{|f_a-f_b|}{BW_{shared}}\right)
\]

with `BW_shared = (BW_a + BW_b)/2`.

Interference power:

\[
I_a^{lin} = \sum_{b\neq a} \eta_{ab} P_{r,b}^{lin}
\]

Noise + background:

\[
N^{lin} = P_{noise}^{lin} + P_{bg}^{lin}
\]

SINR:

\[
SINR_a = \frac{P_{r,a}^{lin}}{I_a^{lin}+N^{lin}}
\]

The script also reports an effective RSSI proxy:

\[
RSSI_{eff,a}(dBm) = RSSI_a(dBm) - 10\log_{10}\left(1 + \frac{I_a^{lin}}{P_{r,a}^{lin}}\right)
\]

## 5.10 Dynamic Human Trajectory Update

At each time step:
- Human position is interpolated from waypoint-time pairs (looping optional)
- All AP-grid links are recomputed with updated attenuation conditions
- Time-indexed `signal/interference/SINR/effectiveRSSI` tensors are updated

## 6. Main Simulation Loop

For every time step `t`:
- Interpolate all human states
- For every grid point `p` and AP `a`:
  - Compute LOS distance/path loss
  - Add obstacle/human attenuation and blockage penalty
  - Add multipath reflected components (if enabled)
  - Add shadowing and small-scale fading
- For each AP `a` at point `p`:
  - Compute co-channel interference from other APs
  - Compute SINR and effective RSSI
- Store outputs in 3D tensors

## 7. Output Data Format

## 7.1 MATLAB `.mat`

Saved variables include:
- `results.signalDbm` with size `[nPoints, nAP, nTimes]`
- `results.interferenceDbm` with size `[nPoints, nAP, nTimes]`
- `results.sinrDb` with size `[nPoints, nAP, nTimes]`
- `results.effectiveRssiDbm` with size `[nPoints, nAP, nTimes]`
- `results.time`, human states, metadata
- `grid`, `aps`, and `sim` structs

## 7.2 CSV columns

`time_s, point_id, x_m, y_m, z_m, ap_name, signal_dbm, interference_dbm, sinr_db, effective_rssi_dbm`

Each row corresponds to one `(time, point, AP)` tuple.

## 9. Parameter Tuning Guide

Key parameters in `defaultSimulationConfig`:

- Geometry/grid
  - `roomDims`, `gridStep`, `gridZLevels`
- Timing
  - `dt`, `simDuration`
- Propagation
  - `pathLossExponent`, `nlosPenaltyDb`, `diffractionPenaltyDb`
- Multipath
  - `enableRayTracing`, `maxReflectionOrder`, `maxReflectionComponents`
- Frequency selectivity
  - `enableFrequencySelective`, `signalBandwidthHz`, `numSubcarriers`
- Random channel effects
  - `shadowSigmaDb`, `smallScaleModel`, `ricianK_dB`
- Interference/noise
  - `ambientNoiseDbm`, `backgroundInterferenceDbm`

AP-level tunables (`createExampleScenario`):
- `position`, `txPowerDbm`, `frequencyHz`, `channel`, `bandwidthHz`

Obstacle-level tunables:
- box geometry + material coefficients

Human-level tunables:
- `radius`, `height`, `attenuationDbPerMeter`, trajectory waypoints and timing

## 10. Computational Complexity and Practical Notes

For `N_p` points, `N_a` APs, `N_t` time steps, and `N_r` reflected components:
- Main complexity is approximately `O(N_t * N_p * N_a * N_r)` plus interference terms.
- Reducing grid density, reflection order, or simulation duration significantly improves speed.

Practical modeling notes:
- This is a high-fidelity engineering approximation, not a full-wave EM solver.
- Diffraction and material physics are simplified for experiment scalability.
- Reflection geometry is room-plane based; obstacle-specific reflections can be added as an extension.

## 11. Extending the Model

Suggested extensions:
- Add UTD/knife-edge diffraction model
- Add obstacle-surface reflections and transmission coefficients by incidence angle
- Add antenna patterns and polarization
- Add temporal channel correlation (Doppler for moving human)
- Add per-subcarrier OFDM channel responses and CSI export
- Integrate localization algorithms directly (KNN, WKNN, particle filter, deep models)
